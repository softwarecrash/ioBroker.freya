# Freya logo concepts

These are comparison drafts. None is wired into `io-package.json` or the Admin UI yet.

1. **Brisingamen Home** — selected. Freya's necklace becomes a ring of context nodes
   around a protected home; the inner three-node tree represents explainable learning.
   The production logo uses deep aubergine, warm gold, and clear turquoise.
2. **Falcon Shelter** — Freya's falcon cloak forms a protective roof above the home.
   More dynamic and mythological, but slightly more detailed at very small sizes.
3. **Freya Circuit Knot** — an abstract `F` crossed by a circuit-like Nordic knot.
   The most technical and compact option, with the weakest immediate smart-home signal.

All concepts retain the existing dark navy, turquoise, and warm gold palette so the
adapter remains recognizable during the rename.
